## 2. 每次运行的记录字段（一题 × 一引擎 = 一行）

| 字段 | 取值口径 | 为什么必须有 |
|---|---|---|
| 问题 ID | Q-01…Q-24 | 基线固定才叫趋势，换题就没有趋势 |
| 引擎 | `chatgpt`／`perplexity`／`gemini`／`copilot` | 这四个是本批**选定**的观测面，台账没规定，属实现选择 |
| 语言／地区 | `en`／`US` | 与 G11 一致：当前只有 en，多语言重开时再扩列 |
| 日期 | 绝对日期 `YYYY-MM-DD` | 「记录波动与日期」的载体 |
| 是否提及 ClosenAI | `是／否／仅品牌名` | 三值而不是布尔，因为「提到但说错」必须能记下来 |
| 引用 URL | 完整 URL 或 `无` | 引用才谈得上 GEO；无 URL 的提及不计曝光 |
| 答案摘要 | ≤40 字，只写它说了什么 | 摘要写长就开始夹带我们的解释，那是自证 |
| 波动标记 | `↑／→／↓／新／失` | 同题同人不同月，靠这一格区分噪声与变化 |

**硬规矩**：同一题同一引擎同一天的两次回答取**两次都记**，不取平均、不取最好——台账 §KG-22 验收写的是
「不把单次 AI 回答当排名」，只记一次就是把单次当排名。

## 3. 停/改/扩阈值（首月校准用的内部建议值，不是行业基准）

阈值是「内部建议值」这四个字的意思：**首月只观察不判死**，首月末按当月实际分布重设并在此表下方留一行变更记录。
第四行故意标成「未启用／不可触发」——把一条现在跑不到判据的规则写成跑得到的规则，是这份表最容易造假的一格。
