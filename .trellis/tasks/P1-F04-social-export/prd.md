# P1-F04: 社交分享导出

## 概述

基于 P0-F06 对话式性格发现的结果，生成"性格类型+占星"组合卡片。比纯 MBTI 更有传播力。性格画像详情（给自己看）与性格名片（给别人看）是同一数据的两种表达。

## 用户故事

作为用户，我希望生成好看的性格名片分享给朋友，这样他们能直观了解我的性格，同时也能帮 App 带来新用户。

## 功能需求

### 1. 性格画像详情 vs 性格名片 — 定位区分

| 维度 | 性格画像详情（给自己看） | 性格名片（给别人看） |
|------|--------------------------|----------------------|
| 定位 | 内省 — 深度自我理解 | 社交 — 可分享的轻量卡片 |
| 信息密度 | 高（AI 行为观察 + 维度分布 + 演化时间线 + 刷新） | 低（类型代码 + 特质标签 + 一句话标语） |
| 独有内容 | AI 观察到的行为模式、性格如何影响 Growth Metrics、性格演化轨迹 | 视觉化设计、Pro 版三维度组合（MBTI+星座+九型）、品牌水印 |
| 维度进度条 | 保留（I/N/T/P 四维度） | 移除（太技术化） |
| 更新频率 | 随对话持续更新（每月可刷新） | 生成后固定，手动重新生成时更新 |
| 入口 | 探索 Tab → 性格画像主体 → "查看完整画像" | 探索 Tab → 性格名片入口 / 性格画像详情页 → "生成名片" |

**设计原则**：详情页做"加法"（信息越来越丰富），名片做"减法"（信息精简好看）。

### 2. 已知道类型导入

用户可选"我已经知道我的类型"直接输入 4 字母，跳过对话式评估（P0-F06 的跳过路径）。

### 3. 性格名片生成

**正面设计：**
- MBTI 类型 + 太阳星座 + 月亮星座
- 个性标语（AI 基于三维度生成）
- 配色：基于 MBTI 类型 + 星座元素自动生成

**示例**："INTP · 太阳天蝎 · 月亮巨蟹 — 用逻辑解构一切情感"

### 4. Pro 版三维度组合名片

- MBTI + 星座 + 九型人格三维度组合
- AI 跨框架关联："你的 MBTI 是 INTP，九型是 5 号'探索者'，太阳天蝎——三种框架都指向你是一个深度思考者"
- MBTI-九型关联表：内置常见组合解读（如 INTP+5号 = "系统构建者"）

### 5. 分享渠道

- 系统分享（微信/朋友圈/Instagram/Twitter）
- 分享落地：他人点击链接 → App Store 下载页（或 Web 预览页）

### 6. 名片变体

- 支持生成多张名片（不同标语）
- 用户选择最喜欢的分享
- 每张名片都是 App 的广告

### 7. 成长报告分享

- Weekly Insight 可分享为图片
- 季度/年度报告可导出为 PDF
- Timeline 热力图可截图分享

## 验收标准
