# P0-F02: Memory Layer（含 Temporal Memory）

## 概述

AI 不只是记住用户说过的话——它持续积累用户的情绪、关系、习惯、成长和人生事件，形成 Personal Dataset（个人数据集）。这不是 Conversation Memory（ChatGPT 也有），而是 Life Memory：过去 120 天的工作压力变化、每周五的情绪下降、和父母聊天频率的降低。Personal Dataset 是竞品无法速成的核心壁垒——用户用得越久，数据越丰富，迁移成本越高。

## 用户故事

作为用户，我希望 AI 记得我上周说过的事并主动问我后续，这样我感觉它在真正关心我，而不是每次都从头开始。

## 功能需求

### 1. 记忆注入机制

每次对话时，AI 结合以下三层上下文生成回复：

- **最近 5 条相关记忆**：通过语义搜索从记忆库中提取与当前话题最相关的 5 条记忆
- **最近 7 天洞察摘要**：来自 P0-F07 成长记录，作为高密度长期上下文让 AI 掌握用户跨天/跨周脉络
- **用户性格画像**：性格类型 + AI 观察到的行为模式 + 用户偏好

### 2. 记忆类型（Personal Dataset 四层）

| 层级 | 内容 | 用途 | 更新频率 |
|------|------|------|----------|
| L1 对话记忆 | 最近 7 天对话的关键事件（人名、事件、情绪、时间、地点） | 日常跟进 | 每日更新（实时流） |
| L2 情绪数据 | 每日情绪签到记录（情绪类型 + 时间戳） | 情绪趋势分析和 Pattern Discovery | 每日更新 |
| L3 性格基线 | 性格类型 + AI 观察到的行为模式 + 用户偏好 | 个性化对话 | 缓慢演化（每月刷新 1 次） |
| L4 成长数据 | 每日洞察摘要 + 关系里程碑 + 重要事件标记 | Life Memory 层——人生轨迹 | 每周聚合（趋势层） |

### 3. 语义记忆搜索

- AI 通过**语义搜索**回忆与当前话题相关的历史记忆（而非简单关键词匹配）
- 让回忆更自然精准
- 搜索范围包含 `current` 和 `superseded` 状态的记忆
- 记忆提取：每轮对话结束后，后端自动提取关键实体（人名、事件、情绪、时间、地点）存入记忆库

### 4. Temporal Memory — 信念演变与记忆版本化

#### 4.1 问题背景

用户的观念、个人信息或倾向会随时间改变。当用户从观点 A 转向对立观点 B，很久后又回到 A 时，AI 如何处理？

**核心矛盾**：不能覆盖（丢失历史）、不能并列（AI 自相矛盾）、不能忽略（失去个性化）。

#### 4.2 记忆状态模型（三态）

每条记忆带**生命周期标签**。记忆不会删除，只改变状态：

| 字段 | 说明 | 示例 |
|------|------|------|
| `status` | 当前状态：`current`（活跃）/ `superseded`（已被取代）/ `reverted`（回归） | `current` |
| `category` | 记忆类别：`values` / `preference` / `relationship` / `goal` / `factual` | `values` |
| `superseded_by` | 被哪条记忆取代（外键，null 表示未被取代） | `memory_1284` |
| `superseded_at` | 取代时间 | `2026-06-15` |
| `transition_reason` | 转变原因（AI 从对话中提取） | "经历了团队重组后开始重视晋升" |
| `reverted_from` | 如果是回归，指向原始 superseded 记忆 | `memory_0892` |

#### 4.3 三阶段处理流程

| 阶段 | 触发条件 | AI 行为 | 记忆操作 |
|------|----------|---------|----------|
| ① 转变检测 | 用户表达与某条 `current` 信念矛盾的内容 | 自然确认："我记得你之前觉得 A，现在想法变了吗？"——不质问，确认这不是情绪化临时表达 | 旧记忆标记 `superseded`，新记忆标记 `current`，记录 `transition_reason` |
| ② 回归识别 | 用户表达与某条 `superseded` 信念高度相似（语义匹配） | "你又回到了 A 的想法——上次你是因为 Z 才转向 B 的，这次是什么原因？" | 旧记忆标记 `reverted`，新记忆 `reverted_from` 指向原记忆 |
| ③ 情绪过滤 | 矛盾表达发生在高强度情绪状态下 | 不标记为转变，记录为"当天情绪波动"。下次对话仍引用原 `current` 信念 | 不改变记忆状态，仅附加情绪标记 |

#### 4.4 AI 表达策略（按记忆状态）

| 场景 | AI 表达 | 设计原因 |
|------|---------|----------|
| 全新观点（无历史） | "这个想法很有意思，跟我多说说" | 不假装认识，自然引入 |
| 观点转变（A→B） | "我记得你之前觉得 A，现在转向 B 了，是什么让你改变了想法？" | 体现记忆连续性，引导反思转变原因 |
| 观点回归（A→B→A） | "你又回到了 A 的想法——上次你是因为 Z 才转向 B 的，这次是什么原因？" | 证明 AI 真正在追踪成长轨迹 |
| 情绪化临时表达 | 不标记转变，下次仍以原观点为基础对话 | 避免"今天吵架就觉得一切都不对"被误判为信念转变 |

### 5. 渐变漂移检测（P0 补充场景）

#### 场景一：渐变式漂移

**问题**：当前设计只检测"单条摘要 vs current 记忆"的矛盾，但最常见的真实情况是**缓慢漂移**——没有任何单条消息与 A 直接矛盾，但 3 个月后整体立场已反转。

**示例**：Day 1 "我觉得 work-life balance 最重要"（A）→ Day 30 "最近也开始觉得想要拼搏一下" → Day 60 "可能趁年轻多冲一冲" → Day 90 "我觉得晋升更重要"（B）。没有任何单条与 A 矛盾，但立场已反转。

**方案**：每周对同一 `category` 的 `current` 记忆做一次 **embedding 趋势分析**——如果最近 4 周摘要向量与该信念的相似度持续下降（如 0.85 → 0.72 → 0.68 → 0.61），触发"渐变提醒"。AI 在 Weekly Insight 中主动确认："我注意到你最近越来越多地提到拼搏和晋升，你对 work-life balance 的想法是不是在变化？"

#### 场景二：引用他人观点被误判为自身信念（P0）

**方案**：记忆写入时增加 `source` 字段——`self`（自身信念）/ `others`（引用他人观点）/ `hypothetical`（假设性讨论）。只有 `source=self` 才参与矛盾检测和转变流程。`source=others` 的记忆仍然存储和可搜索，但不影响用户自身信念状态。

**AI 表达差异**："你朋友觉得享乐最重要——你自己怎么看？"（区分他人观点，引导自我反思）

### 6. 主动跟进触发

- 事件后 3-7 天：AI 主动询问"上次说的事怎么样了？"
- 行运变化与记忆事件关联时：如用户曾提"跟 A 沟通困难"，金星顺行时 AI 主动提示"沟通环境好转，要不要试试跟 A 聊聊？"
- 情绪签到连续负面 3 天：AI 主动发起深度关心对话

### 7. 记忆容量与管理

- 短期记忆保留最近 **50 条**关键事件
- 长期记忆无上限但需用户可管理（查看/删除）
- 用户可在"我的 → 记忆管理"中查看和删除 AI 记住的内容
- 记忆数据加密存储，用户注销时彻底删除

### 8. 成本控制

- 转变检测在记忆写入时用一次轻量级分类完成（判断新记忆是否与某条 current 记忆矛盾），不额外增加 LLM 调用
- 回归识别在记忆注入的语义搜索阶段自然完成（搜索范围包含 superseded 记忆）
- 情绪过滤复用已有的情感分析结果（P0-F03 情绪签到数据），无需新增计算
- **整体增量成本 = 0**

## 验收标准

- [ ] AI 能正确引用 7 天内用户提到的人名、事件、情绪
- [ ] 事件后 3-7 天内 AI 主动发起跟进对话
- [ ] 用户可在"我的 → 记忆管理"中查看和删除 AI 记住的内容
- [ ] 记忆注入不影响对话响应时间（< 3 秒）
- [ ] 记忆数据加密存储，用户注销时彻底删除
- [ ] Temporal Memory 三态正确流转：current → superseded → reverted
- [ ] 转变检测能识别用户观点矛盾并自然确认
- [ ] 回归识别能检测用户回到旧观点并引用转变原因
- [ ] 情绪过滤能区分情绪化临时表达与真实信念转变
- [ ] 渐变漂移检测每周运行，相似度持续下降时触发提醒
- [ ] source 字段正确区分 self/others/hypothetical
