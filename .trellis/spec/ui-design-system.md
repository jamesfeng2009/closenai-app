## 1. 深色宇宙主题

### 1.1 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#050508` | 深空黑，纯黑微蓝调，营造宇宙深邃感 |
| 卡片背景 | `#0F0F1A` | 略亮于主背景，用于卡片/弹窗分层 |
| 金色强调 | `#FFD700` | MBTI 类型大字、Streak 火焰、重要数据 |
| 霓虹紫强调 | `#C084FC` | AI 消息标识、Insight 等级标签、交互高亮 |
| 次要文字 | `#8B8B9E` | 辅助说明、时间戳、空状态文案 |
| 主文字 | `#F0F0F5` | 正文内容 |
| 分割线 | `#1A1A2E` | 卡片分割、Tab 栏分隔 |
| 成功/正面 | `#059669` | 情绪趋势上升、签到完成 |
| 警告/负面 | `#DC2626` | 情绪趋势下降、Streak 中断 |
| 中性/占位 | `#2A2A3E` | 空状态占位、未解锁模块 |

## 2. 4 Tab 结构

### 2.1 Tab 定义（审核安全顺序）

| 顺序 | Tab 名称 | 图标 | 内容 | 审核安全设计 |
|------|---------|------|------|-------------|
| 1 | 成长 | 🌱 | **成长概览仪表盘（首屏默认）** — Today's Reflection + Growth Metrics + Timeline + Insight + AI 入口 | 审核员打开 App 默认落在成长页，非 AI 对话页 |
| 2 | 探索 | 🧭 | **性格画像（主体，占顶部 70%）** + 本命星盘（下方可选入口，30%） | 审核员第一眼看到性格画像（MBTI），不是占星 |
| 3 | Reflect | 📝 | Reflection 界面（AI 对话，降级为第 3 个 Tab） | 命名"Reflect"而非"对话"，弱化工具感 |
| 4 | 我的 | 👤 | 个人资料、记忆管理、对话风格、订阅、设置 | 标准设置页 |

**核心原则**：Tab 顺序"成长→探索→Reflect→我的"确保审核员打开 App 默认落在成长页，而非 AI 对话页。AI 对话从"首屏默认"降级为"第 3 个 Tab"。

### 2.2 默认行为

- 打开 App 默认落在**成长首页**（Tab 1），非 Reflect Tab
- 新用户引导流程后也落地成长首页（非对话页）
- 推送点击后打开 App 也落地成长首页，不直接跳转对话

## 4. AI Card 弱化原则

### 4.1 核心原则

AI 对话在首页中**降级为单行卡片入口**，不是首屏默认。审核员前 3 秒看到的是成长仪表盘，不是聊天界面。

### 4.2 AI 卡片文案规范

| 规范 | 正确示例 | 错误示例 | 原因 |
|------|---------|---------|------|
| 成长记录延续式 | "继续昨天的记录 · 昨天：工作压力" | "我随时都在" | 避免陪伴式表达 |
| 任务式 CTA | "完成今天的 Reflection · 约 30 秒" | "来聊天吧" | 强调成长任务，非聊天 |
| 不展示 AI 回复预览 | 显示未读消息数"2" | 显示 AI 回复内容片段 | 不让审核员第一眼看到聊天内容 |

### 4.3 Reflection Mode（AI 对话页）

Reflection Tab 是 AI 对话界面，但命名"Reflect"而非"对话"，弱化工具感。两种模式：

| 模式 | 触发方式 | 用户场景 | AI 行为 | 结束方式 |
|------|---------|---------|---------|---------|
| Reflection Mode | 用户点击"完成今天的 Reflection" | 每日记录（情绪→挑战→感谢→观察） | AI 生成 Reflection 草稿，用户确认/修改 | 用户确认保存，Card 自动存入 Timeline |
| Conversation Mode | 用户主动点击 Reflect Tab 或从"继续昨天的记录"进入 | 自由聊天、深度探讨 | 自由对话，AI 基于记忆+性格+洞察回复 | 用户主动结束，后台自动提取关键信息更新记忆 |

### 4.4 签到交互（全在对话流内，无浮动卡片）

```
状态 1：AI 消息出现，附带表情快捷回复
┌─────────────────────────────────────────┐

┌─────────────────────────────────────────┐
```

## 6. 过渡动画规范

### 6.1 签到→Reflection 过渡

```
表情放大高亮（0.4s）→ 卡片淡出上移（0.3s）→ 页面右滑入场（0.35s）
→ AI 消息逐条渐入（每条延迟 0.2s）→ AI 首条消息动态填入用户选择的情绪
```

- 总过渡约 0.5s，消息动画 1.5s
- React Native 实现使用 Animated API 或 Reanimated 3

### 6.2 AI 消息流式渲染

- LLM 逐 token SSE 推送，前端逐 token 追加显示
- 打字机效果：每个 token 间隔 10-30ms 渲染
- 流式过程中显示输入指示器（三个跳动的点）

## 7. AI 内容标识（App Store 合规）

所有 AI 消息气泡底部标注"AI 生成"标签。

```css
/* AI 消息气泡 ::after 伪元素统一实现 */
.ai-message-bubble::after {
  content: "AI 生成";
  display: block;
  font-size: 9px;
  color: #8B8B9E;           /* 次要文字色 */
  margin-top: 4px;
  padding-top: 2px;
  border-top: 1px solid #1A1A2E;  /* 分隔线 */
  text-align: right;
}
```

- 标签样式：9px 灰色文字 + 分隔线
- 全局 CSS 伪元素实现，确保所有 AI 消息统一标注
- 不遗漏：所有 `is_ai_generated: true` 的消息必须显示此标签
